# WSL なしで「AI 部下10人」を Windows ネイティブに移植した

Zenn で流行っていた multi-agent-shogun（Claude Code 用のマルチエージェント）を、WSL なしの Windows ネイティブで動かした。将軍＋軍師＋足軽の構成を PowerShell で組み直して、`D:\code\opencode-shogun` に置いた。

<!-- tags: opencode, マルチエージェント -->

## 構成

- モデルは opencode の `big-pickle`（無料）
- Windows Terminal を6ペインに割って、足軽ごとに1ペイン
- `spawn_workers.ps1` でデタッチ起動。WSL の tmux の代わり
- 成果物は Cloudflare Pages にデプロイ

## 結果

第5波で kubobeem3 を3足軽＋軍師に拡張して、`614b1261.kubobeem3.pages.dev` を公開した。

- ビルドは 69.14kB
- `lab.js` が 37.4KB で、13個のシミュレーションが動く
- 足軽2は作業ディレクトリの外に出ようとして拒否され、その分は将軍が直接実装して埋めた

エージェントの分業は、ファイル所有を分けておけば破綻しない。逆に言うと、境界を決めないとすぐ衝突する。今回は足軽ごとに触るファイルを固定した。

## ハマったところ

- 元が WSL 前提で tmux と bash に依存していた。tmux 相当は Windows Terminal のペインで代用
- 足軽が外部ディレクトリを触れずに失敗する。権限を緩めるより、将軍が直接やったほうが早い
- ペインの起動順がずれると、どの足軽が何をやっているか分からなくなる。ペインのタイトルに役割を書いた

※ 足軽を増やすほど、将軍の仕事が増える。
