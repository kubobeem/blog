# 8GB の GPU で動画生成を 176 秒から 55 秒にした

RTX 4060 8GB で ComfyUI + MiniMax H3（w4a8）を動かして、生成時間を詰めた。結論から言うと 3.2 倍になった。

<!-- tags: 生成AI, 動画 -->

## 結果

- 176 秒 → 104 秒 → 55 秒
- pinned memory を有効にしたら 1ステップ 12.3 秒 → 9.95 秒
- ずんだもんの動画が 15.08 秒（短いほう）と 201 秒（長いほう）
- 猫の生成が 95 秒

## やったこと

- モデルは w4a8 の量子化版。8GB に載せるにはこれしかない
- 転送待ちがボトルネックだったので pinned memory を有効化
- ステップ数の削減より、メモリ転送の削減のほうが効いた

8GB の GPU で動画生成をやると、計算より転送で待つ時間のほうが長い。GPU 使用率が低いのに遅い、という状態がずっと続いていた。

## ハマったところ

- 量子化を上げると VRAM には載るが、画質が落ちる。w4a8 が速度と画質の妥協点
- pinned memory は初回確保に時間がかかる。短い生成を連発すると、かえって遅くなることがある
- 解像度を下げるのが一番効くが、それは「速くした」とは言わないので最後の手段にした
