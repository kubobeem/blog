# サイトを1リポジトリにまとめる計画

サイトが増えて散らかってきた。GitHub Pages と Cloudflare Pages が混在していて、どのドメインがどこを向いているのか、自分でも把握できていない状態。

## 現状

- プロフィール、技術系、過去作品の3サイト
- 一部は GitHub Pages、一部は Cloudflare Pages
- 独自ドメインの bare（www なし）は JS リダイレクトで逃げているだけ

## まとめ方

1つのリポジトリに `sites/` を作って、`me` / `tech` / `ninja` を並べる。共通部分は `shared/` に 1990s 風のデザインとして置き、Hono + Vite でビルドする。push したら Wrangler の Actions で Cloudflare Pages にデプロイ。

ドメインの役割はこう決めた。

| サイト | 中身 |
|---|---|
| me | 公式プロフィール + 実験置き場 |
| tech | 簡易ブログ（Markdown → RSS） |
| ninja | 過去作品のショーケース |

`me` と `ninja` の内容がほぼ同じだったので、`ninja` の旧版は消して `me` に一本化する。`blog.kuboes.ninja` と `kubobeem.f5.si` は削除して 301 で飛ばす。

## まだ決めてないこと

- canonical を www にするか bare にするか。仮で www にしてある
- 移行中の挙動。DNS を切り替えると一時的に 404 が出たり、新旧が混ざったりする。me → tech → ninja の順で1個ずつ動かす予定

DNS の変更はダッシュボードで手作業。ここだけは自動化しない。
