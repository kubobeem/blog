# YMM4 のプロジェクトを編集する単一 HTML のエディタを作った

<!-- tags: リバースエンジニアリング, ツール -->

YukkuriMovieMaker4 のプロジェクトファイル（.ymmp）を、ブラウザで開いて編集できるツールを作った。`index.html` 1枚、依存ゼロ、ビルド不要。

## 分かったこと

.ymmp は BOM 付き UTF-8 の JSON。`Timelines[]` / `Characters[]` / `CollapsedGroups[]` という構造で、Item は `$type` による多相、数値は Animator 型の `{Values, Span, AnimationType}` になっている。

手でスキーマを書いていたけど、途中から本物の YMM4 のバイナリから公開 API をリフレクションで全列挙する方針に変えた。実機は `D:\Program Files\YukkuriMovieMaker_v4_Lite` に net10.0 で入っていて、pwsh 7.6.6（.NET 10 host）+ dotnet SDK 10.0.204 で同じランタイムの型が読める。

- 最初の抽出で 201型 / 1,067プロパティ
- フィルタを広げて 1,048型 / 3,007プロパティ（`ymmp-schema.json` 577KB、`.js` 350KB）
- `VoiceItem` は67プロパティあって、自分が v3 で使っていたテンプレートは古いと分かった

IL の逆コンパイルはやらない方針にした。公開 API の列挙と画面キャプチャだけ。

## 動いているところ

- セルフテストは 8件 → 18件 → 20/20 PASS
- プレビューは 960x540 で、字幕と立ち絵のプレースホルダを描画（非黒ピクセル 18,023）
- ドラッグで Frame が 0 → 80、リサイズで Length が 51 → 11 に変わる

## ハマったところ

- **「開く」が無反応だった。** 沈黙が一番悪いので、ページ上にエラーバナーを出すようにした。`label for` でファイル選択を代替し、JSON 貼り付けでの読み込みも足した
- YMM4 が入っていないと誤認していた。実際は同名の別パスに入っていて、しかも net10.0 なので同じランタイムで型が読める
- スキーマ抽出スクリプトで、`ResolveEventHandler` 内の PowerShell コマンド解決が再帰して止まった。リゾルバを純 .NET で書き直した
- 画面キャプチャが別ウィンドウ（ブラウザ）を写していた。`SetForegroundWindow` が拒否されるので `PrintWindow` に変更

検証は python http.server + Playwright。`file://` はブロックされるので HTTP 経由で開く。

※ スキーマを1,048型ぶん書き出して、編集できるのはフレームと長さだけ。
