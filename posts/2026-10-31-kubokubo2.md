# 「You are an idiot」のパロディを自分のドメインで公開した

2000年代の定番いたずらページ「You are an idiot」のパロディを作って Cloudflare Pages に出した。全画面の動画、止まらない音楽、跳ね回るウィンドウ、勝手に増えるポップアップ。要するに迷惑なだけのサイト。

<!-- tags: ネタ, Web -->

## URL

- `kubokubo2.pages.dev`
- `freevibe.kubobeem.tech`
- `xn--u9j9e1eqb2272a.kubobeem.tech`

最後のやつは punycode のまま貼ると「アニフ卥の.kubobeem.tech」になる。ブラウザのアドレスバーには日本語で出るので、リンクを踏んだ人は何のドメインか分からないまま地獄に飛ぶ。

## 中身

`index.html` 1枚。Cloudflare Pages に置いただけ。動画と音は GitHub の raw から借りている。

仕掛けはこうなっている。

- クリック、マウス移動、ウィンドウの外に出る、右クリック、Ctrl / Alt / Delete / F4 のどれでもポップアップが増える
- 増えたウィンドウも同じページなので、そいつらも増やし始める。放置すると指数的に増える
- 親ウィンドウは `moveTo` を 1ms 間隔で呼んで画面の端で跳ね回る
- 閉じようとすると `beforeunload` で「UwU」と引き止めてくる
- ポップアップ側は自分の HTML を `fetch` して Blob URL で開く。初回だけ GitHub に取りに行って、あとはメモリの中だけで増える

最後のやつは我ながら余計なことをした。GitHub に優しい無限増殖。

## 実際どうなるか

ブラウザのポップアップブロックが効くので、初回は1個か2個しか開かない。許可すると本当に増える。増えすぎてタスクマネージャのお世話になる。

音楽はクリックしないと鳴らない（自動再生ポリシーのせい）。動画はミュートで勝手にループする。つまり静かに増える。余計に気持ちが悪い。

## 作った理由

理由はない。ドメインが余っていたから。

`freevibe.kubobeem.tech` と punycode のやつは同じプロジェクトに割り当ててある。中身はほぼ同じで、細かい文言だけ違う。アクセスすると動画が全画面でループするので、URL を踏む人は自己責任で。
