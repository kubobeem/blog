# Gboard っぽい日本語キーボードを clean-room で作った

Gboard の日本語入力が好きだけど、中身がどうなっているか分からないのがずっともやもやしていた。同じ体験を、コードも辞書もアセットも見ずに作り直した。ライセンスは MIT。

## 構成

- Kotlin、minSdk 26 / targetSdk 37
- 日本語変換は Mozc の `libmozc.so`（arm64-v8a）と `mozc.data` を同梱。糊のコードだけ自作
- protobuf のスタブは protoc 3.25.5 の lite で生成

## 動いたところ

v0.2 で APK がビルドできて、ユニットテストは 23 pass。エミュで type → convert → commit → undo まで通る。12キーのフリック入力も入った。

一番の収穫は、**かな→ローマ字の変換テーブルが要らなかった**こと。Mozc の `sendChar` にかなをそのまま渡すと全文字を受け付けてくれて、consumed も true になる。テーブルを書く前提で設計を考えていたので、丸ごと捨てられた。

UI は大きく直した。キーボードの高さを画面の約 28% にして、48dp のストリップ + 4行。キーの間隔は 4dp、文字は行の高さの 48%。最初はキーが 87dp もあって文字が 12sp だったので、指の感覚が全然違う。

## ハマったところ

- 組成が空になったとき BACKSPACE を押すと、残っている文字が勝手にコミットされる。`setComposingText("", 1)` を挟んで回避した
- エミュレータだと画面下端のタップがナビゲーションジェスチャに吸われる。キーボードの当たり判定の問題に見えるけど、環境の問題
- 候補数はエンジンの既定が 9 個。`SET_REQUEST` と `candidate_page_size = 20` で増やせた

音声入力、グライド、手書き、テーマはまだ。優先度は低いので、たぶんやらない。
