# Cドライブの掃除計画を立てた

<!-- tags: PC -->

PC がなんとなく重いので、不要ファイルの洗い出しをした。まず現状把握から。

## 数字を見て分かったこと

- C: 952GB 中、空き 252GB
- RAM 48GB 中、空き 27GB

つまり容量もメモリも足りている。遅さの原因をディスク容量だと思っていたけど、たぶん違う。削除して速くなるのは限定的で、実際に効くのはストレージの整理と起動プロセスの削減だろう、という結論になった。

それでも消す価値はある。開発キャッシュだけで 77GB あった。

| 種類 | 容量 |
|---|---|
| uv | 38.4GB |
| pip | 13.7GB |
| npm | 9.3GB |
| ごみ箱 | 21.5GB |

## 進め方

一気に消すのが怖いので、ドライラン → 選ぶ → 実行 → 空き容量レポート、の段階式にした。

- 削除は各ツールの公式コマンドを使う（手でフォルダを消さない）
- Temp 系は 7 日以上経過したものだけ
- Ollama のモデル、Android SDK、VS Code 拡張、Docker イメージは既定で残す
- 使用中のファイルはスキップして警告を出す。粘らない

ごみ箱の完全削除だけは取り返しがつかないので、確認を挟む。まだ実行はしていない。

※ ドライランだけ書いて、まだ1件も消していない。
