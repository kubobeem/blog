# 35B の MoE を 8GB の GPU で動かして、上限を確定させた

手元の環境で 120k コンテキスト・40 t/s を目標に、35B MoE のチューニングをやった。結論から書くと、目標には届かず、26〜27 t/s がこのハードの上限だと分かった。

## 環境

- Ryzen 5 4500 / DDR4-2666 48GB（4枚混載）
- RTX 4060 8GB（PCIe gen3 x8）
- WSL2 Ubuntu
- モデル: Ornith-1.5-35B-A3B-NVFP4（35B MoE、3B active、40層、experts 256）

## 結果

| 条件 | 前 | 後 |
|---|---|---|
| decode 8k | 約12 t/s | 26〜27 t/s |
| decode 118k | 約11 t/s | 20〜25 t/s |
| 118k 再送 prefill | 177秒 | 5秒（-97%） |
| コールド prefill（11.8万tok） | — | 277秒 |

118k の needle-in-a-haystack も連続で HIT（`prompt_tokens=118027/118029`）。

## 効いた設定

- pin budget 24GB + `moe-cpu-threads 8` → 13.4 → 24 t/s（+86%）
- ReBAR 有効 → 24.0 → 27.0 t/s（+11%）
- q8_0 KV + triton → 13.4 → 15.1 t/s（+13%）
- page-size 16 → 再送 prefill が -97%

## 逆効果だった設定

- RAM の OC（2800 / 3000）は **-30%**。速くしたいのに遅くなる
- `--spec-mtp 3` は -25%
- `--moe-cpu-threads 12` は **-70%**。増やせば速くなるわけではない
- GPU の OC はどのオフセットでも悪化。0 が一番速い
- NVIDIA App の自動チューニングで -6%

## なぜ 40 t/s に行かないか

RAM 帯域が 29 GB/s（AVX2 のみ）で、ここが支配している。加えて PCIe の fetch が 6.6 GB/s しか出ず、expert のミス率が約 40% で固定される。

つまり設定の工夫ではどうにもならない。RAM を2枚挿しにして帯域を出すか、PCIe x16 の環境に移すか。ハードを替えるしかない、という結論で一旦終了した。
