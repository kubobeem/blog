# コマンド1個でニュースの縦型ショートを2本作るようにした

AI と技術のニュースから、15〜30秒の縦型ショートをローカルで自動生成するパイプラインを作った。`/news-video` を叩くと2本出てくる。

## 構成

- Python の単一スクリプト `make.py`（collect / doctor / sfx / build）と `config.yaml`
- 収集は RSS 8本 + HN Algolia + arXiv。出力は `script.json`、`timings.json`、`state/history.json`
- 音声は VOICEVOX 0.25.1 の HTTP API（port 50021）に句ごとに投げて、`ffprobe` で実測長を取る。Whisper は使わない設計
- 映像は ffmpeg。カット、libass で字幕を焼き込み、SFX のミックス、無音の検査まで
- 台本は opencode 自身に書かせる。opencode 側はスキルとコマンドだけ

## 結果

- `doctor` は ALL OK、`collect` で8ソース39件、`build` で2本生成
- 1本目: 17.47秒 / 18 beats（平均 0.97秒）、2本目: 13.80秒 / 11 beats（平均 1.25秒）、どちらも 1080x1920 の 30fps
- SFX は 16個 / 10個、無音の窓は 8/175 と 13/138
- ファイルサイズは 5.50MB→10.4MB、13.03MB→4.6MB と修正で動いた。字幕の焼き込みはピクセル差分 1.6% で確認
- 履歴に2件記録（URL の重複は除外）

## 直したところ

- 生成した画像に崩れた英文が焼き込まれていて「謎画像」になっていた。記事内の実画像（og:image など）を主な光源に変えた。`logo` というキーワードで実画像を誤って除外していたのも直した
- 横長画像を 9:16 で中央クロップしていて、巨大な文字の断片になっていた。contain + ぼかし背景（縮小してから拡大するとボケる）に変更
- 冒頭のノイズの正体は `riser` に使っていた `anoisesrc` のホワイトノイズ。180Hz から 1.5kHz へのトーン掃引に変えた
- ffmpeg で `[fg]` ラベルを二重に使ってグラフが壊れていた。`split` に修正
- 書き込みツールが日本語に無関係な中韓英の文字を混入させたので、codepoint 指定の置換と strict UTF-8 の検証で修復した

尺の計算を音声の実測に寄せたのが効いていて、Whisper を挟まなくても字幕のタイミングは合う。ローカルだけで完結するのも良い。
