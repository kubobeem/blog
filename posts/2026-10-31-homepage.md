# 1990年代風の個人ページを作った

<!-- tags: Web -->

自分のサイトがプレースホルダーのまま数年放置されていたので、開き直って作り直した。狙いは 90 年代のインターネット。白い背景に細い枠、ベベルボタン、点滅する文字。

ページは4枚。トップ、自己紹介、作品、連絡先。依存もビルドも CDN も使わず、素の HTML / CSS / JS だけ。

## 入れたもの

- marquee で流れるお知らせ
- アニメーション GIF
- 訪問者カウンタ
- 点滅する文字
- table レイアウト
- ベベル付きのボタン（`outset`）

名前・作品・画像は `{{...}}` のプレースホルダーにして、後から埋められるようにした。連絡先はフォームを作らず、情報を載せるだけ。フォームはスパムとメンテの温床になる。

## 妥協したところ

90年代の見た目を守りつつ、スマホでも読める最小限のレスポンシブだけは入れた。当時のまま固定幅 760px だと、スマホで確実に事故る。そこは時代に合わせた。

派手なのは見た目だけで、実装は素朴。画像が差し込まれたら完成。
