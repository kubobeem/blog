# 記事の書き方メモ

<!-- tags: このブログ -->

自分用のメモ。記事は `posts/` に markdown ファイルを置いて、`posts.json` にファイル名を足すだけ。

## ファイル名

```
posts/YYYY-MM-DD-slug.md
```

先頭の日付が記事の日付になる。1行目の `# タイトル` が記事タイトルになる。

## 使える記法

見出し、リスト、引用、表、コードブロックあたりは普通に使える。

```
- 箇条書き
- こんな感じ
```

| 項目 | 意味 |
|---|---|
| posts.json | 記事ファイルの一覧（順番は自由） |
| style.css | 見た目 |
| app.js | 読み込みと描画 |

`app.js` は一覧を日付の新しい順に並べるだけ。記事のURLは `/2026-11-04-hello` でも `/#2026-11-04-hello` でも開ける。

※ このメモ自体を守れているかは怪しい。
