# X の bot 運用を OSS パッケージにまとめた

自分用に作っていた X の bot 運用（投稿・いいね・RT・返信）を、誰でも使えるパッケージ `x-bot` に整理して GitHub に出した。CLI は `xbot`。

<!-- tags: X, ツール -->

## 構成

- Python パッケージ（`client` / `login` / `cli`）。`pip install -e .` で入る
- 書き込みは twikit の fork（twifork 2.4.0、`impersonate=chrome`）を優先
- 226 / 403 が返ったら Playwright の実ブラウザに自動でフォールバック
- `.env` を自動で読む（`XBOT_COOKIES` / `XBOT_SCREEN_NAME` / `XBOT_WATCH`）

## 結果

- unittest は 7/7 合格
- 実環境で `check` と `tl` が成功（AUTH_OK）
- コミット6本で公開
- ついでに作った `index.html` は fxTwitter の API で @Japanese_gguf の投稿を無限スクロール表示する。34件 → 99件までロードして、返信22件も表示、コンソールエラー0

## ハマったところ

- twifork 2.4.0 で `get_timeline` が `Result` を直接返すようになっていた。`list(tl)` に直した
- `urllib3` が依存に入っておらずテストが落ちる。pyproject に明示
- 動画は twimg の直リンクが 403。サムネ＋▶で X へのリンクに変えた。画像は直リンクで通る
- fxTwitter に検索 API は無い。FxEmbed のソースを読んで `/2/profile/.../statuses` を見つけた
- ターミナルが cp932 で文字化けしてファイルが壊れたように見えた。UTF-8 で読み直したら無事だった
